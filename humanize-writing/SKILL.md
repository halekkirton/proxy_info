# Humanize Writing（中文写作去 AI 味 25 指令）

## Overview

本 skill 提供一套 25 条中文改写指令，用于把"一眼看出是 AI 写的"文本，改造成读起来像真人、有观点、有细节、有情绪起伏的内容。指令分为四类：语言风格（1-10）、结构调整（11-15）、内容增强（16-20）、细节优化（21-25）。

每条指令包含：**用途说明 → 原始提示词（可直接复制）→ 效果示例**。

## 使用流程

1. **确认文体与目标**：先明确文本类型（公众号、知乎、短视频口播、技术博客、商业报告）和目标平台调性。同样的指令，用在技术博客和娱乐号上力度完全不同。
2. **诊断而非全量套用**：通读原文，找出最突出的 AI 特征（如句式整齐、无个人视角、缺细节、无情绪），从 25 条中只挑 **3-6 条**组合使用。25 条全上会用力过猛，反而更假。
3. **逐条执行，守住核心观点**：一次只应用一条指令，每条都要求"保持原有核心观点/关键信息不变"。改写是换表达方式，不是换立场。
4. **终检**：改写完再通读一遍，检查是否出现新的模板感（比如每段都以"说实话"开头）、事实是否被改错、专业术语是否被过度口语化。

## 常用组合配方

| 场景 | 推荐指令组合 |
|------|-------------|
| 观点型公众号 | 1 + 7 + 20 + 17 |
| 经验分享 / 复盘 | 1 + 5 + 16 + 2 |
| 干巴巴的技术文 | 8 + 24 + 21 + 13 |
| 结构模板感重 | 4 + 12 + 11 + 14 |
| 数据报告 / 分析 | 18 + 5 + 17 + 25 |
| 平铺直叙没人读完 | 19 + 3 + 15 + 10 |
| 整体"太顺滑"像 AI | 6 + 22 + 21 + 23 |

**组合原则**：一次改动里，情绪类（3、9）和结构类（11、15）不要叠太多；数据类（18）必须有真实来源或明确标注为估算。

## 一、语言风格类指令（1-10）

### 指令 1：增加个人色彩

**用途说明**：让客观陈述带上作者立场与亲身经历，适合观点型、经验分享型文章。

**原始提示词**：

```
请对以下文本进行润色,添加更多个人色彩和主观表达:
1. 加入"我认为"、"我发现"、"说实话"等第一人称表达
2. 添加个人经历或感受的描述
3. 使用更有个性的表达方式,而非千篇一律的客观叙述
4. 保持原文的核心观点不变

[粘贴原文]
```

**效果示例**：原文："AI技术的发展带来了效率提升。" 润色后："我亲身体验过,AI技术简直是效率神器!上周我用它写方案,把原来3小时的工作缩短到30分钟,说实话,这种体验太爽了。"

### 指令 2：口语化改写

**用途说明**：把书面腔换成日常说话方式，适合公众号、短视频口播稿。

**原始提示词**：

```
请将以下文本改写成更口语化、更接地气的风格:
1. 用日常对话中的表达方式替换书面语
2. 加入一些口头禅和生活化表达
3. 适当使用网络流行语(但不要过度)
4. 使用简短句和意犹未尽的表达
5. 保持原意不变

[粘贴原文]
```

**效果示例**：原文："该方法具有显著的优势,可以有效提高工作效率。" 润色后："这招简直太绝了,用了之后效率蹭蹭往上涨,根本停不下来!"

### 指令 3：增加情感波动

**用途说明**：制造情绪起伏，避免全文平铺直叙，适合需要感染力的叙事文。

**原始提示词**：

```
请对以下文本进行情感增强处理:
1. 添加情绪化的词汇和表达
2. 在关键点增加感叹和疑问
3. 适当使用强调语气和夸张修辞
4. 在文章中创造情感起伏,而非始终平铺直叙
5. 保持核心信息不变

[粘贴原文]
```

**效果示例**：原文："数据显示这个方法效果很好。" 润色后："数据简直让人惊掉下巴!这个方法的效果好到什么程度?测试结果让我们团队都兴奋得睡不着觉!"

### 指令 4：打破完美结构

**用途说明**：消除"三段式、首先其次"的模板感，适合被吐槽"一看就是 AI 写的"的工整文章。

**原始提示词**：

```
请重新组织以下文本,打破过于工整的结构:
1. 调整段落长度,使其长短不一
2. 打乱过于对称的论点排列
3. 某些部分可以展开详述,而另一些则简明扼要
4. 减少明显的标号和过渡词
5. 保留全部关键信息

[粘贴原文]
```

**效果示例**：原文："本文将从三个方面分析:第一,...第二,...第三,..." 润色后："分析这个问题,我们需要多角度思考。最核心的是...(详细展开)。当然,也不能忽视...(简要提及)。有意思的是,还有一点容易被忽略..."

### 指令 5：增加具体细节

**用途说明**：用数字、时间、场景替换抽象概念，让论述可信可感。

**原始提示词**：

```
请为以下文本添加生动具体的细节:
1. 用具体例子替换抽象概念
2. 添加感官描述(视觉、听觉、触觉等)
3. 加入具体数字、时间、地点等信息
4. 描述具体场景或使用场景
5. 保持原文主旨不变

[粘贴原文]
```

**效果示例**：原文："AI可以提高工作效率。" 润色后："上周二加班到凌晨1点,我用AI帮我整理了253页的市场调研报告,它只用了17分钟就完成了,而且准确提炼出了37个关键数据点。当看到整理好的Excel表格时,我差点激动得把咖啡打翻在键盘上。"

### 指令 6：增加犹豫和不确定性

**用途说明**：模拟人类思考的停顿与自我修正，降低"答案太顺滑"的 AI 感。

**原始提示词**：

```
请修改以下文本,增加一些人类思考中的犹豫和不确定性:
1. 添加表示思考过程的词语("可能"、"也许"、"我在想")
2. 加入一些自我纠正或思考转向
3. 提出问题后自己尝试回答
4. 表达适当的不确定性和思考局限
5. 保持主要观点不变

[粘贴原文]
```

**效果示例**：原文："这个方法有三个优点和两个缺点。" 润色后："这个方法...怎么说呢,我觉得它挺有优势的,比如...等等,可能还是先说说缺点更好?不对,还是按照我原来的思路来吧。它的主要优点应该是..."

### 指令 7：加入反常识或意外观点

**用途说明**：制造认知冲突，提升信息增量和讨论度。

**原始提示词**：

```
请修改以下文本,适当加入一些反常识或出人意料的观点:
1. 挑战1-2个常见假设或传统观点
2. 加入一个出人意料但有理有据的角度
3. 提出一个有创意的类比或比喻
4. 不要过度颠覆原文的核心主张
5. 确保新增内容逻辑自洽

[粘贴原文]
```

**效果示例**：原文："健康饮食对身体有好处。" 润色后："大多数人认为健康饮食就是对身体有好处,但有趣的是,过度追求所谓的'健康饮食'反而可能带来心理负担。我有个朋友,被'健康饮食'的观念折磨得几乎得了饮食障碍。某种程度上,偶尔来个汉堡薯条,对心理健康的正面影响可能超过它对身体的负面影响。"

### 指令 8：增加类比和比喻

**用途说明**：把抽象概念具象化，降低理解成本。

**原始提示词**：

```
请为以下文本增加生动的类比和比喻:
1. 添加2-3个形象的比喻,使抽象概念具体化
2. 使用贴近生活的事物做类比
3. 避免陈词滥调的比喻
4. 确保比喻贴切且易于理解
5. 保持原意不变

[粘贴原文]
```

**效果示例**：原文："数据分析可以发现业务中的问题。" 润色后："数据分析就像企业的CT扫描,能透视出肉眼看不见的业务病灶。好的分析师就像经验丰富的医生,从杂乱的数据指标中,一眼就能找出那些不同寻常的'细胞突变'。"

### 指令 9：加入幽默元素

**用途说明**：通过自嘲、调侃拉近与读者的距离，适合轻松调性的内容。

**原始提示词**：

```
请为以下文本增添适当的幽默感:
1. 加入1-2处轻松的玩笑或自嘲
2. 使用一些诙谐的表达或夸张的比喻
3. 可以适当调侃常见现象或行为
4. 确保幽默恰当,不影响专业性
5. 保持原有信息和观点不变

[粘贴原文]
```

**效果示例**：原文："学习新技能需要时间和耐心。" 润色后："学习新技能就像健身一样,需要时间和耐心——唯一的区别是,你脑力激荡时不会满身大汗,最多就是对着电脑屏幕揪几根头发。说实话,我的编程学习之路已经贡献了我一小撮头发,再这样下去,我可能在掌握人工智能之前就先掌握了'人工秃顶'。"

### 指令 10：加入反问和设问

**用途说明**：用提问牵引读者思考，强化论点节奏。

**原始提示词**：

```
请修改以下文本,增加一些反问句和设问句:
1. 在关键论点前加入设问
2. 用反问句强化某些观点
3. 设置问题后自己解答
4. 通过发问引发读者思考
5. 保持原有论点和信息不变

[粘贴原文]
```

**效果示例**：原文："持续学习对职业发展非常重要。" 润色后："什么因素能真正决定你的职业天花板?是学历?资源?还是运气?我认为,持续学习的能力远比这些因素重要得多。想想看,在这个知识每18个月就翻一番的时代,不学习怎么可能不被淘汰?"

## 二、结构调整类指令（11-15）

### 指令 11：重组段落结构

**用途说明**：调整段落顺序与长短，制造阅读起伏。

**原始提示词**：

```
请重新组织以下文本的段落结构:
1. 调整段落顺序,制造适当的起伏
2. 合并过于零碎的段落或拆分过长段落
3. 某些次要点可以穿插在主要论点之间
4. 避免过于机械的并列结构
5. 保留所有关键信息

[粘贴原文]
```

**效果示例**：原文整齐的三段变成了长短不一、递进关系更自然的四段结构。

### 指令 12：弱化明显的框架词

**用途说明**：去掉"首先/其次/最后"，让逻辑靠内容自然衔接。

**原始提示词**：

```
请修改以下文本,弱化过于明显的结构框架词:
1. 减少"首先"、"其次"、"再次"、"最后"等明显的序号词
2. 用更自然的过渡词替换公式化的转折词
3. 寻找更巧妙的方式表达逻辑关系
4. 保持逻辑连贯性不变
5. 关键信息保持不变

[粘贴原文]
```

**效果示例**：原文："首先,我们要明确目标。其次,制定计划。最后,执行并调整。" 润色后："明确我们想要什么,这是一切的起点。有了清晰的目标,接下来就是规划具体路径了。当然,纸上谈兵不如实际行动,在执行过程中灵活调整才是成功的关键。"

### 指令 13：添加过渡和铺垫

**用途说明**：修补段落间的生硬跳转，提升阅读流动感。

**原始提示词**：

```
请为以下文本添加自然的过渡和铺垫:
1. 在关键转折处增加过渡性表达
2. 为重要观点提前做铺垫
3. 增加前后内容的连接词句
4. 避免观点之间的生硬转换
5. 保持原有内容和逻辑不变

[粘贴原文]
```

**效果示例**：原文中两个段落之间直接跳转的部分,增加了自然的过渡句,使文章流动感更强。

### 指令 14：重写开头和结尾

**用途说明**：强开头（疑问/故事/悬念）加有力量的结尾，并让首尾呼应。

**原始提示词**：

```
请重写以下文本的开头和结尾部分:
1. 开头更有吸引力,可以用疑问、故事或悬念导入
2. 结尾更有力量,给人深思或行动启发
3. 开头和结尾呼应,形成完整感
4. 避免老套的总结性结尾
5. 主体内容保持不变

[粘贴原文]
```

**效果示例**：原本平淡的开头"本文讨论AI技术"变成了"深夜,当你疲惫地加班处理数据时,有没有幻想过有人能帮你分担这些工作?"结尾则从总结性的"AI技术值得关注"变成了"也许,未来的某一天,当AI完成所有繁重工作,我们会重新思考:人类真正的价值到底是什么?"

### 指令 15：制造结构中的惊喜

**用途说明**：在意料之外插入故事或反差，避免全文一个调子。

**原始提示词**：

```
请修改以下文本,在结构中制造1-2处惊喜:
1. 在意想不到的地方插入一个小故事或例子
2. 适当打破常规的内容组织方式
3. 在严肃内容中穿插轻松元素,或反之
4. 安排一个小小的"逆转"或"反转"
5. 保持原有要点和主旨不变

[粘贴原文]
```

**效果示例**：在原本严肃的商业分析中,突然插入一个"说到这个,我不得不分享一个上周发生在我身上的尴尬事..."的小故事,然后又自然地回到主题,增加了文章的趣味性和人情味。

## 三、内容增强类指令（16-20）

### 指令 16：增加故事和案例

**用途说明**：用具体案例支撑抽象论点，增强说服力。

**原始提示词**：

```
请为以下文本增加1-2个相关的故事或案例:
1. 添加真实或虚构但合理的故事
2. 案例应当支持文章的主要观点
3. 故事应该具体、生动,有细节描写
4. 控制故事篇幅,不喧宾夺主
5. 保持原有内容框架不变

[粘贴原文]
```

**效果示例**：原文中的抽象论点"持续学习很重要"增加了一个具体案例:"我有个同事小王,35岁时被裁员,因为他的技能已经过时..."

### 指令 17：增加争议和辩论

**用途说明**：主动呈现反对意见再回应，显得客观可信。

**原始提示词**：

```
请为以下文本增加一些良性争议或辩论元素:
1. 提出1-2个合理的反对意见,然后解释为什么仍坚持原观点
2. 呈现问题的多个角度
3. 承认某些局限性或例外情况
4. 表现出对不同观点的尊重
5. 最终回归并强化原有主张

[粘贴原文]
```

**效果示例**：原文："远程工作提高了效率。" 润色后："远程工作提高了效率——当然,也有人会反驳说,远程工作导致沟通不畅、团队凝聚力下降。确实,我也观察到某些创意工作在面对面环境中更有火花。但权衡利弊,对大多数常规工作而言,远程模式带来的专注度和时间节省,仍然使效率获得了显著提升。"

### 指令 18：加入数据和事实支持

**用途说明**：补充数据、研究、调查，提高内容权威度（**注意：不得编造真实来源**）。

**原始提示词**：

```
请为以下文本添加相关数据和事实支持:
1. 增加2-3处具体数据或研究发现
2. 提供一些事实性的背景信息
3. 引用权威来源或调查(可泛泛提及)
4. 数据应当真实或合理推测
5. 保持原有观点不变

[粘贴原文]
```

**效果示例**：原文："社交媒体影响年轻人心理健康。" 润色后："社交媒体正深刻影响年轻人的心理健康。根据2023年发表在《心理学前沿》上的研究,每天使用社交媒体超过3小时的青少年,抑郁风险增加了42%。更令人担忧的是,一项覆盖14个国家的调查显示,13-19岁年龄段的女孩中,有68%表示社交媒体上的内容让她们对自身形象产生了负面看法。"

### 指令 19：增加悬念和引导

**用途说明**：设置悬念与预告，提升完读率。

**原始提示词**：

```
请修改以下文本,增加悬念和引导元素:
1. 在关键处设置1-2个悬念,吸引读者继续阅读
2. 适当预告后文将要讨论的有趣内容
3. 在段落末尾加入引导性的过渡
4. 可以使用"稍后我会解释"等手法
5. 保持原有内容和结构框架

[粘贴原文]
```

**效果示例**：原文平铺直叙的内容中加入了"这个方法看似简单,但其中暗藏的秘密可能会让你大吃一惊"和"关于这个技术的最惊人应用,我稍后会详细解释"等引导语,增加了阅读期待感。

### 指令 20：加入个人反思

**用途说明**：分享思考转变过程，建立真实感与共鸣。

**原始提示词**：

```
请为以下文本添加个人反思和思考过程:
1. 加入"这让我想到"、"我曾经困惑"等个人思考
2. 分享1-2个与主题相关的个人领悟或转变
3. 表达一些思考过程中的疑惑和突破
4. 反思应当自然,不做作
5. 保持原有主旨不变

[粘贴原文]
```

### 指令 21：多样化句式

**用途说明**：长短句、陈述疑问感叹交替，消除句式单调。

```

### 指令 22：增加细微逻辑瑕疵

**用途说明**：加入轻微跳跃、冗余或不够精确的表达，模拟真人思维节奏。

请为以下文本增加一些细微的人类思维特征:

2. 偶尔使用不那么精确的表达
3. 在次要点上可以略有反复或冗余
4. 适当打破完美的逻辑链

```

### 指令 23：替换形容词和副词

## 通用注意事项

- **力度守恒**：单次改写建议 3-6 条指令；堆叠过多会产生新的、更刻意的"人味模板"。
- **事实不可改**：指令 5、16、18 涉及补充细节和数据，若原文没有对应事实，须明确标注为"示例/假设数据"，不得伪造文献、机构或统计来源。
- **专业场景收敛**：技术文档、合同、财报、医疗等需要精确性的文本，只用 21、23、13 这类句式和过渡类指令，谨慎使用 2、9、22。
- **保留作者口吻**：若原文已有鲜明的个人风格，优先做"减法"（4、12、21、23），而不是叠加更多表演性技巧。
- **终检清单**：改完后自问四件事——是否每段开头都同一种句式？是否出现了原文没有的事实？核心结论是否被改动？是否引入了新的陈词滥调（如"简直就是""yyds""绝绝子"滥用）？

> 最好的 AI 写作是读起来完全感觉不到 AI 的存在,它应该像一个了解你、能准确表达你想法的助手,而不是一个冷冰冰的文本生成器。
